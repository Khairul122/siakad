# SIAKAD

Sistem Akademik Kampus — mono-repo dengan 3 branch independen, masing-masing berisi satu project:

| Branch | Project | Deskripsi |
|---|---|---|
| [`backend`](../../tree/backend) | `siakad-backend` | REST API Laravel + JWT + panel admin Filament v4 |
| [`sistem-akademik`](../../tree/sistem-akademik) | `sistem_akademik` | App Flutter untuk mahasiswa |
| [`dosen`](../../tree/dosen) | `dosen` | App Flutter untuk dosen |

Branch `main` ini sengaja dikosongkan (hanya berisi README ini) — setiap project dikelola independen di branch masing-masing, bukan sebagai folder gabungan.
